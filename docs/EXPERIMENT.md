# 실험 설계

## 질문

비표준 주소 매핑 테이블이 1만 건 이하일 때와 1천만 건 이상일 때, LCS 전수 탐색과 Elasticsearch n-gram 검색의 지연시간과 검색 정확도는 어떻게 달라지는가?

## 독립 변수

- 데이터 규모: 10,000건 / 10,000,000건
- 검색 방식: 모든 후보를 비교하는 LCS / Elasticsearch 2~4-gram 역색인
- 오류 유형: 공백 제거, 행정구역 축약, APT 표기, 한 글자 삭제, 한 글자 치환

## 통제 조건

- 동일 seed로 만든 동일 데이터와 질의 사용
- 알고리즘마다 같은 Top-5 평가 집합 사용
- warm-up 후 1,000개 질의 측정
- 동일 머신에서 다른 고부하 프로세스를 중지하고 최소 3회 반복
- 정확도는 응답 시간이 아니라 정답 ID로만 판정

## 측정 지표

- Top-1 accuracy, Top-5 accuracy, MRR
- p50/p95/p99 latency, throughput(QPS)
- Elasticsearch 인덱싱 시간과 인덱스 크기
- 프로세스 peak RSS와 Elasticsearch JVM heap

## 해석 주의

데이터는 개인정보가 없는 합성 데이터다. 결과는 OCR 모델 정확도가 아니라 이미 추출된 문자열을 표준 주소에 연결하는 **후처리 검색 품질**을 뜻한다. 10M LCS는 매우 오래 걸릴 수 있다. 중단된 실행을 정확한 결과처럼 보고하지 않고 완료 질의 수와 중단 기준을 기록한다.
